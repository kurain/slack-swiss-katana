# 概要
polly for slack のように slack 上の UIでアンケートが取れるツールを作る

# 要件
- claoudflare で hosting する。
- アンケート結果は保存すること
- slack コマンドで /poll <質問内容> でアンケートの作成が始まる
- アンケートの作成は slack 上の画面でできること
- アンケートの回答も slack の UI でできること
- anonymous の投票が可能で、同じユーザーが2度投票できないようにすること
- 質問は、複数の選択肢からの択一ができること
- ある程度リアルタイムに回答状況をわかるようにしたり、投票完了まで結果をかくしたりできること。
